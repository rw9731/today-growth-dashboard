# 新老项目基建门槛回测（11/19）

数据：巨量后台「操作日志」（工具 → 账户工具 → 操作日志；接口 GET /nbs/api/statistics/opt_log/dataSearch?start_time&end_time&page&limit=100&version=1&qt=[]&q_ids=[]&aadvid），Chrome 里只读拉。项目对象的「新建」和「修改 → 新增 视频: 添加: 【素材ID:…】」带时间，能还原每条素材哪天放进哪个项目（删除不算）。416 个智擎户（BigQuery fact 10/1 起有数的户），10/1–11/19，31.5 万条日志、165 万个素材×项目放置；户的日志从开户开始，等于完整记录。
和项目快照比：新项目数基本一致，老项目快照只有日志的一半左右（快照只列近期有活动的项目），基建口径应以日志为准。
冷启：BigQuery fact 上传日 + 后 2 天 ≥ ¥400；去掉星广、星图；新项目 = 项目建在上传日前一天或之后；项目名开头 ios 算 iOS。结果都扣掉日期影响（实际过 ÷ 按上传日冷启率算的期望，O/E）。

## 两个阶段做法不同
- 10/13–11/08（1,173 条）：几乎只建新项目，每条中位进几百个新项目，老项目基本 0。
- 11/09 起（380 条到 11/16）：新老同时推，每个 3 天窗口约新项目 150–400 个、老项目 700–800 个；每条中位新约 19、老约 70。
