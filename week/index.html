三、Use case：哪些能放量、留得住

每个 use case 的标签 = 量 + 次留。能放量 = 周消耗占全盘 3% 以上且不少于 ¥2 万，其余是量小。次留好 = 次留率 ≥ 30%（Reina 11/18 定，不看次留成本）；低于 30% 时才和全盘比：次留率不低于全盘、次留成本不高于全盘也算好；次留差 = 次留率低于全盘 85%；次留贵 = 次留率没问题，但次留成本超过全盘 1.2 倍；次留一般 = 介于两者之间；样本不够 = 激活不到 50。下面分组：能放量、留存好 = 能放量，次留率不低于全盘，次留成本不高于全盘；量中等、留存好 = 周消耗占 1% 以上、激活 150 以上，次留率不低于全盘、次留成本不高于全盘；能放量、留存不达标 = 能放量但次留不达标；留存差 = 里面留存最差的，加上量小留不住或 Use case 库里已暂停的。绿 = 次留率不低于全盘，或次留成本不高于全盘，红 = 次留率低于全盘 85% 或次留成本超过 1.2 倍。周消耗占比不到 1%、又不在「留存差」里的不列。
