三、Use case：哪些能放量、留得住

每个 use case 的标签 = 量 + 次留。量：能放量 = 周消耗占全盘 3% 以上且不少于 ¥2 万；量中等 = 占 1% 以上；量小 = 不到 1%。次留：次留好 = 激活 50 以上，次留率至少 30% 且不低于全盘，次留成本不高于全盘；次留好但贵 = 次留率够，次留成本超过全盘 1.2 倍；成本略高 = 次留率够，次留成本超过全盘但不到 1.2 倍；次留差 = 次留率低于全盘 85%，或次留率没到线且次留成本超过 1.2 倍；次留一般 = 次留率没到线，但没差到这个程度；样本不够 = 激活不到 50。颜色看次留，深浅看量。下面分组：能放量、留存好 = 能放量，次留率至少 30% 且不低于全盘，次留成本不高于全盘；量中等、留存好 = 周消耗占 1% 以上、激活 150 以上，次留率至少 30% 且不低于全盘、次留成本不超过全盘 1.1 倍；能放量、留存不达标 = 能放量但次留不达标；留存差 = 里面留存最差的，加上量小留不住或 Use case 库里已暂停的。绿 = 次留好（至少 30%）或次留成本不高于全盘，红 = 次留率低于全盘 85% 或次留成本超过 1.2 倍。周消耗占比不到 1%、又不在「留存差」里的不列。
